# UITM Student Portal - Advanced Web Design Project

## Project Overview
A comprehensive student portal web application developed for the IMS566 - Advanced Web Design Development and Content Management course. This portal provides students with an intuitive interface to manage their academic activities, view grades, track course progress, and access important announcements.

## Features

### ✅ Authentication System
- Login page with form validation
- Demo credentials pre-filled for testing
- Password visibility toggle
- Quick login with demo credentials
- Form validation with real-time feedback
- Secure session management

### ✅ Responsive Navigation
- Bootstrap 5 navigation bar
- Mobile-friendly hamburger menu
- Active page highlighting
- Theme toggle (light/dark mode)
- Consistent navigation across all pages

### ✅ Dashboard Page
- Quick stats overview (CGPA, Courses, Attendance, Hours)
- Three interactive data visualizations:
  - Attendance pie chart (Chart.js)
  - CGPA progress line chart
  - Course completion bar chart
- Latest announcements section
- Quick actions panel
- Upcoming deadlines tracker

### ✅ Data View Pages (2 Pages)

#### 1. Courses Page
- Complete course listing with filtering options
- Course progress visualization
- Upcoming assignments and deadlines
- Course details modal view
- Export functionality

#### 2. Grades Page
- Current semester grades table
- GPA history chart
- Grading system reference
- Academic achievements display
- Performance summary statistics

### ✅ Profile Management
- Personal information display
- Academic details
- Profile picture upload (click photo to change)
- Edit profile modal
- Contact information management

### ✅ Additional Features
- Dark/Light theme toggle
- Toast notifications system
- Print functionality
- Mobile-responsive design
- Form validation
- Local storage for user preferences

## Technical Implementation

### Frameworks & Libraries
- **Bootstrap 5** - Responsive CSS framework
- **Chart.js** - Data visualization library
- **Bootstrap Icons** - Icon library
- **Google Fonts (Poppins)** - Typography
